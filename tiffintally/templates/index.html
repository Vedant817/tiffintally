What this page does and does not do

  • Your sheet stays in this browser session. Another visitor does not see it. The copy lives in the server process until restart. Do not put a shared deploy online without a login.
  • Partial privacy masking. Each paste gets an in-memory token map. All sender display names, their first-name aliases, names immediately following roommate/friend/dost, and recognized phones, emails and numbered addresses are masked. Other names and addresses can still reach a configured model. This is not anonymization. Turn hosted extraction off for sensitive exports.
  • Reconciler. Cancels and quantity changes are applied in timestamp order in Python. The language model, when one is used, only proposes events.
  • No auto-send. Payment reminders are drafts you copy. There is no WhatsApp Business API key in this app.
